# 撰写"现有研究基础、条件、手段以及指导教师情况"

## 这个skill做什么

帮助用户撰写科研申报书中展示研究基础和团队能力的部分。这一部分要向评审专家证明"我们有条件、有能力完成这个项目"，是可行性论证的重要组成部分。

核心挑战：这一部分高度个性化，必须基于申请人的真实情况撰写。skill的作用是提供结构框架、写法指导和语言规范，具体内容需要用户提供真实信息。

## 输入要求

### 必需输入（申请人必须提供真实信息）
1. **前期研究成果**：在相关方向已发表的论文、已完成的项目等
2. **依托单位/实验室信息**：实验室名称、级别、主要设备等
3. **指导教师信息**：姓名、职称、研究方向、代表性成果、承担项目等

### 重要输入
4. **计算资源与实验条件**：GPU型号/数量、数据集、软件平台等
5. **团队其他成员**：参与者及其分工（如适用）
6. **前期预研成果**：与本项目直接相关的初步实验结果或方法验证

## 撰写流程

### 第一步：收集信息

向用户收集上述输入信息。如果用户没有完整提供，逐项询问。提醒用户：
- 这一部分不能编造，所有信息必须真实可查
- 论文、项目等信息应提供具体名称和编号

### 第二步：按四个子节组织内容

#### X.1 研究基础（约200-400字）

**写法要点**：
- 概述申请人在相关方向的研究积累
- 用"长期围绕X开展研究"开头定位研究方向
- 列举2-4个具体的研究方向/成果，与本项目的研究内容形成对应
- 如有直接相关的预研成果（如初步实验结果、方法原型），在此重点说明

**句式参考**：
- "项目负责人长期围绕X开展研究，在A、B、C等方向具备较扎实的研究基础。"
- "前期工作中，已在X方面取得了Y进展，为本项目研究奠定了Z基础。"
- "已在相关领域发表学术论文X篇，其中CCF A/B类X篇。"

#### X.2 研究条件（约150-300字）

**写法要点**：
- 说明依托单位/实验室的平台条件
- 列举关键硬件资源（GPU型号和数量、存储等）
- 提及可用的软件平台和数据资源
- 如有国家级/省部级重点实验室等资质，在此说明

**句式参考**：
- "本项目依托[实验室名称]，该实验室拥有[设备描述]，可满足本研究的计算需求。"
- "实验平台配备X块[GPU型号]GPU，总算力达Y，能够支持大规模模型训练与评测。"

#### X.3 研究手段（约200-400字）

**写法要点**：
- 概述推进研究的工作方式和方法论
- 按"文献跟踪→理论分析→算法设计→实验验证→学术交流"的顺序展开
- 每个环节用1-2句话说明具体做法

**典型结构**：
```
首先，持续跟踪[相关方向]的国内外前沿进展，系统梳理相关理论基础和技术路线；
其次，针对项目中的关键科学问题开展有针对性的模型分析与算法设计；
再次，依托现有计算平台和实验条件，开展充分的仿真实验与对比分析；
最后，通过与课题组成员及相关研究人员的持续交流讨论，不断拓展研究深度与广度。
```

#### X.4 指导教师情况（约200-500字）

**写法要点**：
- 指导教师的基本信息（姓名、职称、研究方向）
- 代表性学术成果（论文、项目、获奖等）
- 与本项目的相关性说明
- 指导教师能为项目提供的具体支持

**注意**：指导教师信息的详细程度取决于申报要求，有的只要求简要介绍，有的要求详细CV。

### 第三步：审查与优化

检查以下要点：
1. **研究基础与项目内容的对应性**：前期成果是否支撑本项目的研究方向？
2. **条件的充足性**：实验条件是否满足研究需求？
3. **信息的真实性**：所有信息是否真实可查？
4. **篇幅控制**：总字数约800-1500字（视申报要求调整）

## 写作风格规范

### 语言风格
- **客观陈述**：用事实说话，避免自我评价性语言
- **具体量化**：论文数量、GPU型号、项目经费等尽量给出具体数字
- **简洁直接**：信息密集，不用过多修饰

### 论证逻辑
- **前后呼应**：研究基础中提到的成果/能力应与项目研究内容有逻辑关联
- **能力匹配**：展示的条件和能力应足以支撑项目研究的实施
- **适度展示**：充分但不夸大，避免给人"炫耀"之感

## 注意事项

1. **必须基于真实信息**：所有内容必须可查证，不能编造论文、项目或条件
2. **注意申报级别差异**：不同级别（青基、面上、重点研发等）对研究基础的要求不同
3. **避免与"可行性分析"重复**：这里侧重"有什么"，那里侧重"为什么可行"
4. **个人信息保护**：注意脱敏处理敏感信息（如身份证号、具体联系方式等）
5. **与项目内容的关联**：每个能力点都应与项目研究内容有关联，不要列举无关成果
