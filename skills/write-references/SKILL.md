# 撰写"立项依据-参考文献"——文献调研与整理

## 这个skill做什么

帮助用户进行面向科研申报书撰写的系统性文献调研，并整理规范的参考文献列表。参考文献不只是格式问题——哪些文献被引用、引用在哪、覆盖了哪些方向，直接影响申报书的学术说服力。

核心职责：
1. **指导文献调研策略**：根据研究主题确定需要覆盖的文献方向
2. **辅助文献检索**：配合 academic-search skill 进行文献搜索
3. **整理参考文献列表**：按规范格式编排，确保覆盖面合理

## 输入要求

### 必需输入
1. **研究主题与核心问题**
2. **已完成的申报书各部分内容**（尤其是研究目的与意义、研究现状分析等）：帮助确定已引用的文献和需要补充的方向

### 过程输入（调研过程中逐步补充）
3. **各研究子方向的代表性工作**
4. **近三年的前沿成果**
5. **国内外覆盖比例**

## 文献调研策略

### 确定文献覆盖方向

根据研究主题，按以下维度确定需要覆盖的文献方向：

1. **基础理论与技术**：研究对象本身的核心技术论文（如多模态模型的基础架构论文）
2. **评测与基准**：该领域的评测基准和标准化工作
3. **攻击/威胁研究**：已知的威胁类型和攻击方法
4. **防御/方法研究**：已有的防御方法和技术路线
5. **特定子方向**：与项目研究内容直接对应的专门研究
6. **综述性工作**：该领域的综述论文，帮助快速了解全貌

### 文献检索要点

- **时间覆盖**：以近3年为主，经典工作可回溯至5年
- **来源覆盖**：顶级会议（AAAI、NeurIPS、ICML、CVPR、ACL等）和期刊为主
- **国内外比例**：以国际前沿工作为主，适当引用国内代表性成果
- **数量参考**：一般项目15-30篇，重点项目30-50篇

### 文献选择原则

1. **代表性优先**：每个子方向选最具代表性的工作，不追求全面穷举
2. **引用有据**：每篇文献都应在正文中有明确的引用位置和引用理由
3. **覆盖均衡**：各子方向都有文献支撑，不要只集中在某一条主线
4. **时效性与经典性兼顾**：以最新进展为主，但开创性/奠基性工作也应引用
5. **自我引用适度**：如果有团队前期工作，适当引用但不过度

## 撰写流程

### 第一步：梳理已有引用

1. 阅读已完成的申报书各部分
2. 提取正文中已出现的所有引用标记[1][2]...[N]
3. 确定每个引用指向的具体文献信息（如尚未完整，需补充）
4. 分析引用的覆盖面：哪些方向引用充分？哪些方向缺少文献支撑？

### 第二步：补充文献调研

对覆盖不足的方向，配合 academic-search skill 进行文献检索：
- 按子方向逐一搜索
- 每个子方向收集3-5篇代表性工作
- 记录每篇文献的完整元信息

### 第三步：编排参考文献列表

按以下格式编排：

```
参考文献
[1] Author1, Author2, Author3, et al. Title [C/J]//Venue, Year.
[2] ...
```

**格式规范**：
- [C] 表示会议论文（Conference）：`Title [C]//Conference Name, Year.`
- [J] 表示期刊论文（Journal）：`Title [J]. Journal Name, Year.`
- 多作者用逗号分隔，超过3人用"et al."
- 编号按正文中首次出现的顺序排列

### 第四步：检查引用一致性

确保参考文献列表与正文引用完全对应：
- 正文中出现的每个引用标记在列表中都有对应条目
- 列表中的每篇文献在正文中都被引用
- 引用编号按出现顺序递增，无跳号

## 输出格式

```
参考文献
[1] [完整文献信息]
[2] [完整文献信息]
...
[N] [完整文献信息]
```

## 输出与状态管理

### 输出文件
完成撰写后，将内容写入 `<output_path>/4-参考文献.md`（output_path 由 `write-proposal` skill 管理，从 `proposal-state.json` 中读取）。

### 状态更新与回调
完成本section撰写后，**必须调用 `write-proposal` skill**，传入以下信息：
- 已完成的section编号：`S4`
- 完成状态：`draft_done`（初稿完成）或 `revised`（修订后）
- 工作摘要：一句话概括本次完成的工作

`write-proposal` 将更新 `proposal-state.json` 和 `proposal-log.md`，并给出下一步建议。

## 注意事项

1. **不要编造文献**：如果某篇文献的具体信息无法确认，应标注"待确认"并建议用户核实
2. **引用编号与正文对应**：参考文献编号必须与正文中出现的顺序一致
3. **格式统一**：全文使用同一种引用格式（国标GB/T 7714或申报书要求的格式）
4. **文献质量**：优先选择顶级会议/期刊发表的论文，避免引用来源不明的预印本（除非是该领域的标准预印本如arXiv）
5. **与正文协同**：文献调研不是孤立的工作，应与申报书各部分的撰写同步推进，确保引用支撑到位
