# 撰写"特色创新点+年度研究计划+预期研究成果"

## 这个skill做什么

帮助用户撰写科研申报书最后的研究方案部分，包含三个子部分：
1. **特色与创新点**：项目最核心的创新贡献
2. **年度研究计划**：项目的时间规划和里程碑
3. **预期研究成果**：项目将产出的具体成果

这三部分共同回答"这个项目新在哪、怎么安排、能得到什么"。

## 输入要求

### 必需输入
1. **研究目标和研究内容**（已完成的部分）：创新点必须对应研究内容
2. **研究方法**（已完成的部分）：创新点应源于方法设计
3. **项目执行期限**：通常2-3年

### 重要输入
4. **申报级别**：影响创新点的表述方式和预期成果的要求
5. **团队发表能力**：预期论文数量应与团队能力匹配
6. **已有成果基数**：帮助合理设定增量目标

## 撰写流程

### 第一部分：特色与创新点（约800-1500字）

#### 整体定位段（约50-100字）

```
本项目针对[核心问题]，从[A、B、C]三个维度进行系统研究，
其特色与创新之处主要体现在以下三个方面：
```

#### 每个创新点的论证（约200-400字/个，共3个）

**创新点标题格式**：
"提出了[方法/技术]的[应用/方案]"

**论证结构**：
1. **问题定位**（约50-100字）：
   - "针对当前研究工作中'A'以及'B'问题"
   - 用"本项目不再/不单纯依赖X，而是Y"突出差异
2. **创新方法**（约100-200字）：
   - 描述创新的核心方法
   - "其创新之处在于：首次[做了什么]"
   - 说明方法的关键机制
3. **创新价值**（约50-100字）：
   - "这一方法解决了[问题]"
   - "为[目标]提供了[支撑]"
   - "填补了[空白]"

**写法要点**：
- 每个创新点对应一个研究内容/方法
- 创新点之间不要有大量重叠
- "首次""提出了""构建了"等动词精准使用
- 创新描述要具体，不要泛泛说"有创新性"

### 第二部分：年度研究计划（约400-600字）

#### 结构

按年度分阶段，每年包含：
- 阶段时间范围
- 主要研究任务（对应哪条研究内容）
- 具体工作内容（3-4项）
- 里程碑/关键产出

**写法模板**：
```
4.1 年度研究计划
本项目的研究期限为[起始年月]至[结束年月]，计划分为N个阶段实施：

(1) 第一年度（[时间范围]）：主要完成[任务概述]，重点开展研究内容1研究。
具体包括：
    - [工作1]；
    - [工作2]；
    - [工作3]。

(2) 第二年度（[时间范围]）：主要开展研究内容2研究。
具体包括：
    - [工作1]；
    - [工作2]。

(3) 第三年度（[时间范围]）：主要开展研究内容3研究，并集成前两年度成果。
具体包括：
    - [工作1]；
    - [工作2]；
    - [工作3]。

项目在研期间，计划参加相关领域高水平国际学术会议X-Y人次，
并与国内X领域的研究团队开展学术交流。
```

**计划编制原则**：
- 第一年侧重基础工作和第一个研究内容
- 中间年份按研究内容的逻辑顺序推进
- 最后一年侧重集成、验证和成果总结
- 每年应有明确的里程碑产出

### 第三部分：预期研究成果（约300-500字）

#### 成果类别

按以下类别组织预期成果：

**（1）理论/技术方面**（约100-150字）：
```
针对[核心问题]，建立一套"[方法1]—[方法2]—[方法3]"的[技术体系]。
具体成果包括：
    - [技术成果1]；
    - [技术成果2]；
    - [技术成果3]；
```

**（2）工具/应用方面**（约50-100字）：
```
开放/发布[数据集/工具/平台]；
开源[原型工具/系统]，支持[功能]；
```

**（3）学术论文方面**（约50-100字）：
```
在[期刊/会议级别]上发表学术论文X篇以上；
```
- 论文数量应与申报级别匹配
- 列出目标期刊/会议名称

**（4）知识产权方面**（约30-50字）：
```
申请国家发明专利X-Y项。
```

#### 成果数量参考

| 申报级别 | 论文数量 | 专利数量 | 数据/工具 |
|---------|---------|---------|----------|
| 青基 | 3-5篇 | 1-2项 | 视情况 |
| 面上 | 5-8篇 | 2-3项 | 建议 |
| 重点研发 | 8-15篇 | 3-5项 | 必须 |

**注意**：数量应根据团队能力和项目周期合理设定，不宜过高或过低。

## 写作风格规范

### 创新点部分
- **精准**：每个创新点有明确的定位和边界
- **自信但不夸大**：用"提出了""构建了""解决了"等确切动词
- **有据**：创新点应能在研究方法部分找到对应的技术方案
- **"首次"慎用**：确实属于首次提出的才能用"首次"

### 年度计划部分
- **可行**：每年安排的任务量应合理
- **递进**：各年度之间有逻辑递进关系
- **量化**：里程碑尽量可量化

### 预期成果部分
- **务实**：成果数量和类型应与项目规模匹配
- **可验证**：成果应能在结题时明确判断是否完成
- **覆盖全面**：理论、技术、论文、专利等多类型成果

### 字数参考
- 特色与创新点：约800-1500字
- 年度研究计划：约400-600字
- 预期研究成果：约300-500字
- **总计：约1500-2500字**

## 输出格式

```
3. 特色与创新点
[定位段]

（1）[创新点1标题]
[论证段落]

（2）[创新点2标题]
[论证段落]

（3）[创新点3标题]
[论证段落]

4. 年度研究计划及预期研究成果
4.1 年度研究计划
[各年度计划]

4.2 预期研究成果
(1) 理论与技术方面：...
(2) 工具应用方面：...
(3) 学术论文方面：...
(4) 发明专利方面：...
```

## 输出与状态管理

### 输出文件
完成撰写后，将内容写入 `<output_path>/9-创新点与计划.md`（output_path 由 `write-proposal` skill 管理，从 `proposal-state.json` 中读取）。

### 状态更新与回调
完成本section撰写后，**必须调用 `write-proposal` skill**，传入以下信息：
- 已完成的section编号：`S9`
- 完成状态：`draft_done`（初稿完成）或 `revised`（修订后）
- 工作摘要：一句话概括本次完成的工作

`write-proposal` 将更新 `proposal-state.json` 和 `proposal-log.md`，并给出下一步建议。

## 注意事项

1. **创新点不要与研究方法重复**：研究方法描述"怎么做"，创新点论证"新在哪"
2. **创新点数量适中**：一般3个，不超过4个；太多显得分散，太少显得单薄
3. **年度计划要可行**：评审会判断计划是否合理，过于激进或保守都不好
4. **预期成果要可验证**：承诺的成果应能在结题时明确交付
5. **成果数量要合理**：过高显得不切实际，过低显得投入不足
6. **与前面部分的逻辑衔接**：创新点对应研究内容，计划覆盖研究方法，成果回应研究意义
