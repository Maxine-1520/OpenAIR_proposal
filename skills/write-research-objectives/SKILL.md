# 撰写"研究目标、研究内容和拟解决的关键问题"

## 这个skill做什么

帮助用户撰写科研申报书中研究方案的开篇部分，包含三个紧密关联的子部分：研究目标（总目标）、研究内容（做什么）和拟解决的关键问题（核心科学/技术难题）。这一部分是整个研究方案的纲领，后续的研究方法、可行性分析等都以此为依据展开。

核心挑战：研究目标要清晰凝练，研究内容要具体完整，关键问题要精准深入——三者之间必须形成从"做什么"到"怎么做"到"难在哪"的递进逻辑。

## 输入要求

### 必需输入
1. **研究目的与意义**（已完成的部分）：确保研究目标与立项依据的论证逻辑一致
2. **核心研究问题**：项目聚焦的关键问题
3. **研究方法概要**：打算用什么方法（帮助确定研究内容的展开方式）

### 重要输入
4. **文献综述中的不足**：研究内容应对应文献综述中指出的不足
5. **项目特色/创新点**：帮助确定关键问题的凝练角度
6. **申报级别**：影响研究内容的深度和广度

## 撰写流程

### 第一部分：研究目标（约300-500字）

**写法要点**：
- 用1段话完整阐述项目总目标
- 先用1句概括性定位："本项目面向X，围绕Y，目标是Z"
- 然后用"一方面...另一方面...此外..."展开三个层面的子目标
  - 一方面：对应第一个研究方向的子目标
  - 另一方面：对应第二个研究方向的子目标
  - 此外：对应第三个研究方向的子目标
- 最后用"通过上述研究，力求..."收束

**句式框架**：
```
本项目面向[问题场景]，围绕[研究主题]开展研究，目标是形成[总体目标]。
一方面，针对[问题1]，研究[方法1]，[目标1]；
另一方面，针对[问题2]，研究[方法2]，[目标2]；
此外，考虑到[现实约束]，进一步研究[方法3]，[目标3]。
通过上述研究，力求为[应用场景]提供[支撑]。
```

### 第二部分：研究内容（约500-800字）

**写法要点**：
- 用1段概括性文字开头，说明研究内容的总体布局
- 然后用编号（1）（2）（3）（4）逐条展开具体研究内容
- 每条研究内容包含：
  - 问题背景（为什么要研究这个）
  - 研究什么（具体的研究任务）
  - 预期产出（期望得到什么结果/方法）
- 最后用"通过上述研究，形成..."总结技术路线

**每条研究内容的写法**：
```
（1）面向[场景]，针对[问题]，研究[方法/机制]，
    建立/构建/提出[技术方案]，为[目标]提供支撑；
（2）针对[问题]，研究[方法/机制]，
    构建/设计[技术方案]，以提高[性能/能力]；
...
```

**研究内容的组织原则**：
- 一般设3-4条，覆盖项目的主要研究方向
- 各条之间应有逻辑递进关系（如：训练阶段→推理阶段→部署阶段）
- 每条内容应与一个关键问题对应
- 每条内容应是后续研究方法部分要详细展开的对象

### 第三部分：拟解决的关键问题（约800-1500字）

这是最重要的部分，也是 write-key-problems skill 的核心。每个关键问题按以下结构展开：

#### 每个关键问题的论证结构（约200-400字）

1. **问题标题**：用"X条件下Y的Z问题"格式，精准定位问题
2. **背景与现状**（约100-150字）：
   - 描述问题产生的场景和原因
   - 用"与传统X不同，本问题..."突出特殊性
3. **已有证据**（约50-100字）：
   - 引用前期研究或已有材料中的发现
   - "已有材料表明/显示..."
4. **核心问题凝练**（约100-150字）：
   - "基于此，本项目拟重点解决的问题是：如何..."
   - 明确问题的边界和约束条件

**关键问题的写法要点**：
- 标题用完整论点句，不要用简单短语
- 问题描述要从"现象"深入到"机理"，不要停留在表面
- 已有证据为问题存在提供支撑，增强说服力
- 核心问题用"如何..."句式，明确问题的研究性质
- 每个问题的约束条件要写清楚（如"不依赖X""在Y条件下"）

**总结段**（约100-150字）：
```
通过本项目研究，可较系统地解决[研究对象]在[条件]下面临的若干关键问题，
包括[问题1]、[问题2]、[问题3]和[问题4]等，
为构建[目标]提供具有针对性的关键技术支撑。
```

## 写作风格规范

### 语言风格
- **精确**：每个研究内容和关键问题都有明确边界
- **层次分明**：研究目标→研究内容→关键问题，层层递进
- **逻辑严密**：三者之间形成完整的对应关系

### 对应关系要求
- 研究目标中的"一方面/另一方面/此外"应对应研究内容中的（1）（2）（3）
- 研究内容中的每条应对应一个关键问题
- 关键问题应与文献综述中指出的不足形成呼应

### 字数参考
- 研究目标：约300-500字
- 研究内容：约500-800字
- 拟解决的关键问题：约800-1500字（每个问题200-400字）
- **总计：约1500-3000字**

## 输出格式

```
1. 研究目标、研究内容和拟解决的关键问题
1.1 研究目标
[总目标段落]

1.2 研究内容
[概括段落]
（1）[研究内容1]
（2）[研究内容2]
（3）[研究内容3]
（4）[研究内容4]
[总结]

1.3 拟解决的关键问题
（1）[关键问题1标题]
[论证段落]

（2）[关键问题2标题]
[论证段落]

...

[总结段]
```

## 注意事项

1. **研究目标不要太空泛**：避免"全面解决X问题"这类无法实现的表述，用"形成X方案/路径/支撑"
2. **研究内容要具体可操作**：每条内容应能在研究方法部分找到对应的技术方案
3. **关键问题要精准**：不是简单复述研究内容，而是指出每个内容中"最难的部分"
4. **与立项依据的衔接**：研究目标应呼应"研究目的与意义"中提出的问题
5. **为后续部分铺垫**：这里的每条研究内容都将在"研究方法"部分详细展开
6. **注意与 write-key-problems skill 的关系**：本skill覆盖整体框架，write-key-problems提供关键问题部分的更深入指导
