# 撰写"立项依据-国内外研究现状分析和发展趋势"

## 这个skill做什么

帮助用户撰写科研申报书中"国内外研究现状分析和发展趋势"部分。这一部分是立项依据的核心支撑，需要系统梳理研究领域的国内外进展，准确把握已有工作的贡献与不足，为项目研究的必要性提供文献依据。

核心挑战：不是简单地罗列文献，而是要在系统梳理的基础上建立"已有工作做了什么→还有什么问题没解决→这些问题为什么重要"的论证链，自然地引出本项目的切入点。

## 输入要求

### 必需输入
1. **研究主题与核心问题**：项目要研究什么？核心问题是什么？
2. **已有文献调研材料**：文献列表、综述文章、开题报告中的相关工作部分等

### 重要输入
3. **研究方案概要**：项目打算怎么做？（帮助判断需要在文献中寻找哪些"不足"来支撑）
4. **项目特色/创新点**：项目与已有工作的差异（帮助确定文献梳理的对比维度）
5. **申报级别**：影响文献覆盖面和论述深度要求

## 撰写流程

### 第一步：文献归类与主线梳理

根据已有材料，将文献按研究主线归类。典型归类维度：

- **评测与基准研究**：有哪些基准？评测了什么维度？覆盖了哪些模型？
- **攻击方法研究**：攻击类型有哪些？攻击载体如何演变？代表性工作？
- **防御方法研究**：从哪些层面做防御？方法如何演进？局限性？
- **特定子方向研究**（如后门安全、对齐方法等）：有无专门研究？进展如何？

每个子方向按时间线或方法论演变线梳理，呈现从早期到最新、从简单到复杂的发展脉络。

### 第二步：逐节撰写

每条研究主线按以下结构展开：

```
### X.X [子方向名称]研究

[1-2句定位]：该方向在整个研究领域中的定位和重要性。
[代表性工作梳理]：
  - 工作1[引用]做了什么，发现了什么。
  - 工作2[引用]在此基础上推进了什么。
  - 工作3[引用]进一步解决了什么问题。
[小结]：该方向的进展和仍存在的不足。
```

**写法要点**：
- 每个代表性工作用1-3句话精炼概括其核心贡献，不要逐篇复述
- 工作之间用"例如""其后""另一类工作""与之相近""值得注意的是"等过渡词串联
- 适时引用文献标记（[7][8][9]等）
- 段落开头用1-2句话定位该子方向，结尾用1-2句话总结进展与不足

### 第三步：研究现状总结

设专门的总结小节（如"X.X 研究现状分析及总结"），完成以下任务：

1. **概括四条（或N条）主线**：用一句话概括每条主线的代表性工作和特点
2. **过渡判断**："总体来看，该方向正在由'发现问题'向'建立体系'过渡"
3. **逐条列出不足**：用编号列表（（1）（2）（3）（4））列出当前研究存在的不足

**不足的写法**：每条不足 = 已有进展的概括 + "但" + 具体不足

典型不足句式：
- "现有X分别强调A、B、C，但不同工作之间的D差异较大，尚未形成E"
- "A研究快于B研究。A已经扩展到C、D等更复杂形式，而B仍以E为主"
- "现有研究仍偏重A，B不足"
- "与A相比，B研究的C仍明显不足"

### 第四步：发展趋势预判

基于近三年的前沿成果，从以下角度预判4条左右的发展趋势：

```
第一，[评测维度]将由A走向B。[简述理由]。
第二，[攻击/方法维度]将继续向C方向发展。[简述理由]。
第三，[防御/技术维度]将由D转向E。[简述理由]。
第四，[新兴方向]将成为F中的新增长点。[简述理由]。
```

趋势预判要基于文献中的实际演变方向，不要凭空想象。

## 写作风格规范

### 语言风格
- **客观综述**：用"已有研究表明""相关工作指出""研究发现"等客观表述
- **精炼概括**：每个工作1-3句话，不逐篇复述全文
- **评价克制**：对已有工作用"推动""扩展""推进"等中性动词，不用"完美""突破性"等夸大词
- **文献密集**：关键论点都应有文献标记支撑

### 组织原则
- **按研究主线分节**，不是按时间线或逐篇罗列
- **每条主线内按方法论演变**组织（从简单到复杂、从单一到系统）
- **先梳理贡献，再指出不足**（先立后破）
- **总结小节统一归纳不足**，不要在每个子方向中分散批评

### 引用规范
- 正文中用方括号标记[1][2][3]等
- 多篇连续引用可用[1-5]格式
- 引用应覆盖国内外代表性工作
- 避免只引用某一团队或某一年的工作

### 字数参考
- 每条研究主线：约300-500字（含引用）
- 研究现状总结：约300-500字
- 发展趋势：约200-400字
- **总计：约2000-4000字**（视申报级别调整）

## 输出格式

```
2. 国内外研究现状分析和发展趋势
2.1 [第一条研究主线]
[正文]

2.2 [第二条研究主线]
[正文]

2.N [最后一条研究主线]
[正文]

2.N+1 研究现状分析及总结
[总结段落]

第一，[趋势1]
第二，[趋势2]
...
```

## 注意事项

1. **不要写成流水账**：避免逐篇论文复述，要按方法论脉络组织
2. **不要只列不评**：每条主线末尾应有总结评价，指出已有进展和不足
3. **不足要对应项目内容**：总结中的不足应与项目拟解决的问题形成呼应
4. **发展趋势要有据**：基于文献演变方向推断，不要脱离文献凭空预测
5. **与"研究目的与意义"的分工**：这里侧重"别人做了什么"，那里侧重"为什么要做"；避免大量重复论述
6. **文献引用位置**：每个代表性工作、每个关键数据都应有引用标记，但引用标记要自然嵌入句中，不要堆砌
